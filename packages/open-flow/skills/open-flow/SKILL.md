# Open Flow

Use `<!-- agentic:var flowCommand -->` to operate the selected deployment.
Consult the references relevant to the task:

- [Flow capabilities and examples](references/flow-authoring.md): inspect, edit,
  connect, validate, run and publish; import/export workflow templates; online entries and Flow enable/disable;
  concurrency and Run diagnostics.
- [n8n conversion](references/flow-n8n-conversion.md): represent collections,
  branches, provider operations and state while preserving source behavior.

Keep generated Flow and node names short enough to scan on the canvas. Aim for
2–4 English words or 4–8 Chinese characters, using the user's language unless
the workflow has an established naming language. Name a Flow by its main purpose
and a node by its action and object, such as `AI Trend Digest`, `Fetch trends`,
`Verify sources`, or `发布文章`. Keep only qualifiers needed to distinguish similar
nodes. Put detailed behavior in descriptions; avoid sentences, repeated workflow
context, and obscure abbreviations. Preserve names explicitly supplied by the
user, and do not rename unrelated existing nodes.

<!-- agentic:if localDevelopment -->

Run commands from this repository's root. The development CLI connects to the
existing local Server by default, using `OPEN_FLOW_PORT` (default `3001`) and
`OPEN_FLOW_TOKEN`, or the token generated by `bun run dev`. It reads the root
`.env`. If the local Server has not been started, report that prerequisite.
Do not start or reconfigure a Server merely to perform a Flow operation.

To select another Server, the user must provide both `OPEN_FLOW_URL` and
`OPEN_FLOW_TOKEN` in the environment. Never read, print, or copy credential files
into prompts or command arguments. Connector and LLM configuration stay on the
Server; do not duplicate them in the CLI.
<!-- agentic:endif -->

Keep the requested boundary: editing a Draft does not authorize a Run,
publication, or enabling automatic execution. Inspecting an entry does not
by itself authorize invoking it. For edits, report the Flow and Revision,
verification result, and unresolved configuration. For a publication, report
the Publication and available online entries. For a query, report the observed
online state.
